# Brand assets

No approved VIZORA logo or favicon was supplied for the F0 build, so a
**placeholder** mark is in use. To adopt the approved assets:

1. Drop the approved files here (e.g. `vizora-logo.svg`, `vizora-mark.svg`).
2. Replace the SVG in `components/brand/logo.tsx` (the only place the mark is rendered).
3. Replace `app/icon.svg` (favicon) and, if supplied, add `app/apple-icon.png`
   and `app/opengraph-image.png`.
