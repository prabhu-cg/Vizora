# Brand assets

`vizora-logo.svg` is the approved mark, unmodified. The app renders the same
two paths in `components/brand/logo.tsx` (the left wing uses `--brand-ink` so it
stays visible in dark mode; geometry and the right-wing colour are unchanged).
`app/icon.svg`, `app/favicon.ico` and `app/apple-icon.png` are derived from it.
